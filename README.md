# CatScript 🐾

Welcome to **CatScript** — the ultimate, most beautiful, and hilariously lazy esoteric programming language inspired entirely by cat behavior! 

Every single command has a mandatory fixed delay of **5 milliseconds** because cats are never in a hurry.

## ⚙️ Features
- **100% Pure Cat Language**: No human words like `if`, `while`, or `print`. Only gestures and sounds!
- **Safe & Clean**: No bad words or hard crashes, just graceful cat bites.
- **Fixed Speed**: Operates at a relaxed pace to prevent your high-tech CPU from overheating.

## 📜 Full Command Reference

### 🥩 Food & Math
- `Meow` — Ask for food (+1 to the belly)
- `Hiss` — Disapprove the portion (-1 from the belly)
- `MeowMeowMeow` — Scream at 4 AM (+10 to the belly)
- `HissHissHiss` — Furious spitting (-10 from the belly)
- `Tygydyk` — Midnight zoomies (multiply belly by 2)
- `Share` — Regurgitate half of the food (divide belly by 2)
- `Churu` — Premium liquid treat (multiply belly by 5)

### 🫗 Destruction & Interruption
- `Drop` — Stare into human's eyes and push a glass off the table (reset belly to 0)
- `Puke` — Total body cleanse (wipe belly and memory completely)
- `Bite` — Gentle bite! Gracefully stops the program

### 📢 Human-Cat Interface
- `Purr` — Happy vibration (print belly value as an ASCII character)
- `Scream` — Loud meow (print belly value as a regular number for debugging)
- `Stare` — Hypnotize the human (read 1 character from keyboard)
- `Sniff` — Curiously smell the floor (read an integer from keyboard)

### 📦 Secret Hiding Spots
- `Burry` — Hide food under the pillow (save belly value to memory)
- `DigOut` — Recover hidden treats back to the belly

### 🧠 Cat Logic & Conditions
- `EyesWide` — Stare at an invisible ghost on the ceiling (if belly > 0, execute next line, otherwise skip)
- `EarsBack` — Flatten ears (the `else` block, executes only if `EyesWide` failed)

### 🔄 Laziness & Jumps
- `TailUp` — Lift tail. Start of the loop (repeats until belly is 0)
- `TailDown` — Lower tail. End of the loop
- `Sleep` — Fall asleep on the keyboard (pause program execution for 5 seconds)
- `Lick` — Meticulously clean the fur (does absolutely nothing, wastes 5 ms)
- `LaserPointer` — Spot the red dot (jump 5 lines forward)
- `ChaseTail` — Try to catch own tail (jump 5 lines backward)

## 💻 How to Run
Create a file named `hello.cat` and run it via command line:
```bash
python catscript.py hello.cat
```
